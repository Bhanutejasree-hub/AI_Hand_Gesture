# AI_Hand_Gesture
The AI Hand Gesture Recognition System is a computer vision project that detects and recognizes hand gestures. It uses Python and MediaPipe for hand tracking and gesture recognition. The system was tested with four gestures: Open Palm, Closed Fist, Thumb Up, and Victory.

## Features
- Detects and tracks a hand using camera input.
- Recognizes four basic hand gestures.
- Uses hand landmark information to identify gestures.
- Demonstrates real-time hand tracking and gesture recognition.
- Provides a foundation for touch-free human-computer interaction.

## Technologies Used
- Python
- MediaPipe
- OpenCV
- Google Colab

## Gestures Recognized

| Gesture | Description |
|---|---|
| Open Palm | All fingers are extended. |
| Closed Fist | All fingers are folded. |
| Victory | Index and middle fingers are raised. |

## How It Works

1. Capture a frame from the camera.
2. Process the frame using the hand-tracking model.
3. Detect hand landmarks.
4. Analyze landmark positions and finger movements.
5. Identify the gesture and display the predicted label.


## Applications
- Touch-free computer interaction.
- Gesture-based device control.
- Assistive technology.
- Human-computer interaction.
- Interactive learning systems.

## Conclusion

This project provided practical experience with computer vision, hand tracking, and gesture recognition using Python and MediaPipe. It demonstrates how hand landmarks can be used to recognize simple gestures and create the foundation for touch-free interaction systems.
